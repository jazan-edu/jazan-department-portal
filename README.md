# بوابة القسم الداخلية — Jazan Department Portal

هذا المستودع يحتوي على **الكود المصدري فقط** لبوابة القسم الداخلية وجميع المنصات المرتبطة بها (Google Apps Script).

⚠️ **لا يحتوي هذا المستودع على أي بيانات فعلية** (لا شيتات بيانات، لا ملفات شواهد/مخرجات، لا معلومات شخصية كأرقام هوية أو جوالات أو أسماء موظفين). فقط أكواد `Code.gs` و `Index.html` الخاصة بكل منصة.

## البوابة (Portal)

ملف [`index.html`](./index.html) في جذر المستودع هو بوابة القسم — واجهة موحّدة (قائمة جانبية + iframe) تجمع روابط جميع المنصات مصنّفة حسب الفئة، وتُستضاف على GitHub Pages:

**https://jazan-edu.github.io/jazan-department-portal/**

لإضافة منصة جديدة: انسخ أي مقطع منصة داخل مصفوفة `PLATFORMS` في `index.html` والصقه، ثم عدّل الفئة والاسم والأيقونة والرابط. أسماء الأيقونات المتاحة مكتوبة فوق قائمة `PATHS` في نفس الملف. المنصة بدون رابط (`url: null`) تظهر تلقائياً كـ "قريباً".

## ملاحظة تقنية مهمة

جميع منصات `doGet()` تحتاج السطر التالي حتى تُفتح داخل iframe (كما في البوابة):

```javascript
.setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL)
```

وبعد أي تعديل على الكود في محرر Apps Script، لازم إنشاء **إصدار جديد (New version)** من قائمة Deploy → Manage deployments حتى ينعكس التعديل على الرابط المنشور فعلياً.

## أدوات القسم وروابط الوزارة

- `tools/watermark.html`: إزالة العلامة المائية من خطابات PDF. «إزالة ذكية» تحذف العلامة من محتوى الملف ويبقى النص قابلاً للتحديد، و«تنظيف بالصورة» للملفات الممسوحة مع إمكانية مسح منطقة محددة. المعالجة في المتصفح بنسخ محلية من pdf-lib و PDF.js داخل `tools/vendor/`، ولا يُرفع الملف.
- `tools.html?tool=sign`: توقيع PDF بالرسم أو بصورة PNG/JPG، مع اختيار الصفحة والحجم والموضع والتراجع، ثم تنزيل نسخة جديدة. المعالجة في المتصفح ولا يتم رفع المستند أو التوقيع؛ المرفقات لا تُحفظ بعد مغادرة الأداة. الإضافة صورة توقيع وليست شهادة توقيع رقمي.
- `tools.html?tool=qr`: إنشاء رمز للرابط أو النص (بما فيه العربية)، وتنزيل PNG أو SVG.
- روابط نور وفارس وأعمالي والدعم الموحد تفتح بتبويب مستقل عبر `external: true`، لتجنب مشكلات تضمين صفحات تسجيل الدخول.
- أعمالي يستخدم `https://aamali.moe.gov.sa/` كما في [صفحة الوزارة](https://www.moe.gov.sa/aamali/Pages/default.aspx)، بدل عنوان ADFS الذي يحتاج سياق دخول.
- الدعم يستخدم `https://usc.moe.gov.sa/moe_csm` من [صفحة الوزارة](https://www.moe.gov.sa/ar/aboutus/Portal/Application/Pages/usp.aspx)، بدل رابط المصادقة الذي يحتوي TransactionId مؤقتًا.

### تطوير الأدوات

يتطلب Node.js 22.15 أو أحدث. شغّل `npm ci` ثم `npm test` و`npm run build`.
المصدر في `src/`، والملفات المنشورة والمكتبات المرخّصة ضمن `assets/`. يجب تضمين ملفات البناء في commit لأن GitHub Pages يعرضها مباشرة. يغطي الاختبار قراءة QR بالعربية، وتصدير التوقيع على صفحات PDF مقصوصة ومدوّرة في الاتجاهات الأربعة، وسلامة روابط البوابة.
